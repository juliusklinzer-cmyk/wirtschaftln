Primary action button — use for any tap target. Modern, soft-cornered, brand-colored.

```jsx
<Button variant="gold" size="lg" iconLeft="🍺" onClick={save}>Eintragen</Button>
```

Variants: primary (Münchner Blau, default), gold (ceremonial CTA), secondary (outline), ghost, danger (Kasse/penalty). Sizes sm/md/lg. Props: fullWidth, disabled, iconLeft/iconRight. Press = gentle scale-down.
