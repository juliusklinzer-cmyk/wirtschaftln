Tavern collectible card: photo, district, StarRating, visit status. `naechstes` flags the upcoming venue (gold frame); `besuchtAm` flips to "Besucht". Exports `StarRating` too.

```jsx
<WirtshausCard name="Augustiner-Keller" photo={img} bezirk="Maxvorstadt" rating={4.6} besuchtAm="11. Apr 2026" />
```
